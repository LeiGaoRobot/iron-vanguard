隐私政策

本政策适用于 Android 版《钢翼先锋》(包名 com.leigaorobot.ironvanguard)以及本站发布的网页版。简单来说:本游戏不收集、不上传、不分享任何个人信息。

我们收集的信息

无。游戏没有账号、登录、广告、统计分析、崩溃上报或任何第三方 SDK。

权限与网络

  • Android 版不申请任何系统权限,也没有网络权限(INTERNET),无法联网。
  • 游戏的全部代码、模型和字体都打包在安装包里,运行时不会访问任何服务器。
  • 不会读取通讯录、位置、相机、麦克风、存储中的照片或文件、设备标识符等。

保存在你设备上的数据

  • 游戏进度(资金、已购买的强化与部件、勋章、最佳成绩)和设置(音量、灵敏度、所选机体与任务)保存在本机的 WebView 本地存储(localStorage)中。
  • 这些数据只存在于你的设备上,不会被发送给我们或任何第三方。
  • 卸载游戏,或在系统设置中为本应用"清除数据",即可将其全部删除。

网页版

网页版托管在 GitHub Pages 上。游戏本身同样只在浏览器本地存储中保存进度;但网页版加载时会请求 Google Fonts 字体,GitHub 和 Google 作为托管与字体服务方可能按其各自的隐私政策记录访问日志(如 IP 地址)。Android 版不涉及这一点。

儿童

本游戏不收集任何人的个人信息,包括儿童。

政策变更

如果今后的版本加入了联网、广告、统计或任何会处理个人信息的功能,我们会在发布前更新本页面并修改生效日期。

联系我们

对本政策有疑问,请在 GitHub Issues 留言。

Privacy Policy

This policy covers the Android app Iron Vanguard (package com.leigaorobot.ironvanguard) and the web version published on this site. In short: the game does not collect, upload or share any personal information.

Information we collect

None. The game has no accounts, sign-in, ads, analytics, crash reporting or third-party SDKs.

Permissions and network

  • The Android app requests no system permissions, including no network (INTERNET) permission, so it cannot go online.
  • All code, models and fonts ship inside the package; the game contacts no server while running.
  • It does not read contacts, location, camera, microphone, photos or files in storage, or device identifiers.

Data stored on your device

  • Game progress (credits, purchased upgrades and parts, medals, best times) and settings (volume, sensitivity, chosen mech and mission) are kept in the WebView's local storage (localStorage) on your device.
  • This data stays on your device and is never sent to us or anyone else.
  • Uninstalling the game, or using "Clear data" for the app in system settings, deletes all of it.

Web version

The web version is hosted on GitHub Pages. The game itself likewise keeps progress only in the browser's local storage, but the page loads fonts from Google Fonts, so GitHub and Google, as the hosting and font providers, may log requests (such as IP addresses) under their own privacy policies. This does not apply to the Android app.

Children

The game collects no personal information from anyone, including children.

Changes

If a future version adds networking, ads, analytics or anything else that processes personal information, this page will be updated, with a new effective date, before that version is released.

Contact

Questions about this policy can be posted on GitHub Issues.
