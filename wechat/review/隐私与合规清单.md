# 《钢翼先锋》提审前的隐私与合规清单

> 2026-11-19 按当前 `wechat/src/` 代码整理。代码里只要新增了下表没有的 `wx.*` 接口，就回来对一遍。
> 带「后台」的项要在 mp.weixin.qq.com 小游戏后台操作，代码做不了。

## 1. 用户隐私保护指引（后台 → 设置 → 基本设置 → 服务内容声明 → 用户隐私保护指引）

微信要求：小游戏调用了涉及用户信息的接口，就必须在指引里声明，否则接口会直接报错（`api scope is not declared in the privacy agreement`），提审也会被打回。

| 接口 | 代码位置 | 收集的信息 | 指引里要不要声明 |
|---|---|---|---|
| `wx.setClipboardData` | `src/diag.js`（启动失败诊断弹窗，点「复制」把报告写进剪切板） | 剪切板 | **要**，勾「剪切板」，用途写「启动失败时复制诊断报告，便于用户反馈问题」 |
| `wx.getSystemInfoSync` | `src/adapter.js`、`src/quality.js`、`src/diag.js` | 设备型号、系统版本、性能等级 | 不在隐私接口清单里，无需勾选；建议在指引正文里写一句「读取设备性能等级用于自动选择画质」 |
| `wx.reportEvent` | `src/stats.js` | 任务开始 / 结束、失败原因、广告奖励结果（不含任何个人身份信息） | 不需勾选接口；指引正文写「统计关卡完成情况，用于调整难度」 |
| `wx.setStorageSync` 等 | `src/adapter.js`（localStorage） | 存档、设置，只存在手机本地 | 不需声明 |
| `wx.createRewardedVideoAd` | `src/ads.js` | 由微信广告组件处理，游戏本身拿不到任何用户信息 | 不需勾选；开通流量主后按后台提示补广告相关说明 |
| `wx.shareAppMessage` / `onShareAppMessage` / `onShareTimeline` | `src/ads.js` | 无（卡片只带任务编号 `m=<key>`） | 不需声明 |
| `wx.createGameClubButton` | `src/hud.js` | 无（打开游戏圈由微信处理） | 不需声明 |
| `wx.getMenuButtonBoundingClientRect` | `src/hud.js`（首胜卡片的箭头指向右上角胶囊） | 无 | 不需声明 |

没有用到的：`getUserInfo` / `getUserProfile`、手机号、位置、相册、相机、麦克风、通讯录、蓝牙、`wx.login`、订阅消息。以后要接排行榜（`getFriendCloudStorage` / 开放数据域）或登录，必须先补指引。
