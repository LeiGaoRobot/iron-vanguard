`make_icon.py` 生成五个方案，1152px 绘制后 LANCZOS 缩到 144 和 512。
配色取自 `site/index.html` 的界面主色：底 `#0b0d10`、青 `#5fe3ff`、琥珀 `#ffc23c`、红 `#ff4a3a`，
装甲灰白对应 `closeups_mech.jpg` 里的主角涂装。

```
D:\AI\comfyui-venv\Scripts\python.exe make_icon.py
```

输出 `out/`：

**选定 `A_visor`（2026-11-18）**，已复制成本目录的 `icon_144.png`（上传微信用这个，144×144 RGB PNG 15 KB）
和 `icon_512.png`（宣传图/放大用）。换方案改脚本末尾的 `FINAL` 再重跑即可。

| 方案 | 内容 | 适合的名字 |
|---|---|---|
| `A_visor` | **已选用**。机甲头正面，V 形天线 + 贯穿式发光眼缝 | 任何机甲向名字 |
| `E_face` | 面罩特写，单眼横缝 + 下颌格栅 | 同上，更硬核 |
| `B_wing` | 翼徽，推进翼 + 菱形核心 + 尾焰 | 钢翼先锋 / 钢翼 |
| `C_combo` | 机甲头 + 背后推进翼 + 尾焰 | 钢翼先锋 |
| `D_word` | 中文字标 + 面罩小剪影 | 字数为 2 的任何名字 |

每个方案出 `_144.png`（直接上传微信）和 `_512.png`（留作宣传图/放大用）。
`contact.jpg` 是五个方案的对比图，右侧小图是 144px 的方形和圆形裁切预览。

## 注意

- 微信头像要求 png/bmp/jpeg/jpg/gif、不大于 2M、建议 144×144，这里的 `_144.png` 都满足。
- 微信头像同时以方形和圆形两种形式展示，所以所有元素都收在以中心为圆心、半径约 66px 的安全圈内，
  四角只有背景。改图形坐标时要保持这条，否则圆形预览会切掉翼尖或耳部。
- 改名字只需改 `icon_word()` 的 `text` 参数：`icon_word('铁翼', 'D_word')`。
- 背景网格的疏密在 `background()` 里的 `step`，144px 下太密会有摩尔纹，当前 12px 一格是测过的。
